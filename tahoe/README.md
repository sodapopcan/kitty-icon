# MacOS Tahoe 26 Icon Set
The icons are all 1024x1024 and made with the Icon Composer template.

NOTE: Please use these at your own risk and keep a backup of the original 512 x 512 version before copying any of these to your `kitty.conf` folder. 

Even though these were made with the correct template, I could not get well-defined behaviour between MacOS and how it chooses to harmonize the scale and tint of these icons in the MacOS Dock.
